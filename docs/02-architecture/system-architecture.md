## 数据流

### 知识写入流

```
用户/AI对话 → 接入层 → Agent层(提取) → 核心层(维护判断)
                                         ├── 向量检索找候选
                                         ├── LLM 判断关系
                                         └── 写入知识图谱 + 建立关系
```

### 知识检索流

```
用户提问 → 接入层 → Agent层(Main Agent spawn Knowledge Agent)
                       └── 核心层：直接检索 → 间接加载 → 渐进式加载
                              └── Agent 整理 → SSE 推送结果 + 溯源标记
```

## 模块职责

| 模块 | 职责 | 依赖 |
|------|------|------|
| 接入层 | HTTP/MCP 请求处理，认证，流式推送 | 核心层 |
| Agent 层 | 问答编排，知识探索，React Loop | 核心层, LLM Harness |
| 核心层 | 知识提取/图谱/生命周期/检索的业务逻辑 | DB, LLM, Embedding |
| 基础设施层 | 数据库、LLM调用、文档存储、向量生成 | 无 |
| 前端层 | 管理界面、问答界面 | 接入层 |

## 部署架构

- **后端**：单一 FastAPI 进程（内置 MCP Server），可水平扩展
- **数据库**：PostgreSQL 16（TimescaleDB + pgvector），单实例
- **存储**：MinIO（开发）/ AWS S3（生产）
- **Embedding**：本地 GPU（BGE-M3），开发环境
- **前端**：两个独立 SPA 应用，通过 REST API + SSE 与后端通信
