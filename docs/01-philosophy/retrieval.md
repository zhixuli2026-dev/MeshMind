# 知识检索

知识被索引和呈现给 Agent 的方式。三种检索途径互相配合，覆盖不同的知识发现场景。

## 三种检索方式

### 1. 直接检索（Direct Retrieval）

知识通过匹配算法被**主动命中**。

| 手段 | 说明 |
|------|------|
| **BM25（分词检索）** | 基于关键词精确匹配，适合明确术语和短语查找 |
| **向量检索（Vector Search）** | 基于语义相似度，适合模糊查询和语义匹配 |

直接检索是最常见的入口：Agent 提问 → 匹配相关知识摘要 → 返回。

### 2. 间接加载（Indirect Loading）

知识**并非直接匹配查询**，而是因为与其他知识点的关联关系，被动地被拉入上下文。

```
查询命中知识点 A
  → A 关联了 B（前置条件）
  → A 关联了 C（互补）
  → B 和 C 并未直接匹配查询，但因关联被间接加载
```

这种方式让检索结果自带上下文，而不需要 Agent 二次查询。

### 3. 渐进式加载（Progressive Loading）

知识摘要在生成时，往往来源于一个或多个**知识文档**。摘要与文档之间存在连接。

```
查询命中 知识摘要（L2）
  → LLM 判断当前信息不足
  → 沿"摘要→文档"的链接深入
  → 加载关联的原始文档（L3）
```

这是一种**按需深入**的检索：先给摘要，不够再加载文档。避免了一开始就返回完整文档造成上下文爆炸。

## 检索流程总览

```
用户/Agent 提问
  → ① 直接检索：BM25 + 向量搜索命中相关摘要
  → ② 间接加载：沿知识图谱关系边拉入关联知识点
  → ③ 渐进式加载：LLM 判断不足时，从摘要深入原始文档
  → 返回上下文给 Agent
```
