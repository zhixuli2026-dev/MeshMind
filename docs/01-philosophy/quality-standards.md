# 项目质量标准

MeshMind 定位为**精品项目**，前端和后端都有明确的品质要求。

## 总体标准

- 代码质量与设计品位同等重要
- 不做"能用就行"的功能，做"让人满意"的体验
- 每一个细节都要经过设计，不允许粗糙的实现

## 前端：Apple Style

前端设计对标 Apple 的设计语言：

- **简洁**：去除一切不必要的元素，让内容成为焦点
- **精致**：间距、圆角、阴影、动画缓动曲线都需精心调试
- **流畅**：过渡和动效自然，不卡顿、不跳跃
- **克制**：颜色使用克制，留白充足，层级清晰
- **可信**：溯源标记清晰，让用户能验证每一个回答

## 后端：可靠性优先

### LLM 路由

- 模型调用的路由层需精心设计
- 支持多模型切换和 fallback
- 请求重试、超时控制、速率限制
- 错误处理优雅，不让 LLM 异常影响用户体验

### LLM Harness

- LLM 调用的安全护栏
- 输入校验和清洗
- 输出质量控制
- 成本和延迟监控
- 结构化输出的可靠性保证

## 评判标准

如果用户/开发者用起来觉得"粗糙"、"不可靠"、"难用"，就是没达到标准。
