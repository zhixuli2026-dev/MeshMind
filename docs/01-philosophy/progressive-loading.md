# 渐进式加载（Progressive Loading）

渐进式加载是贯穿 MeshMind **知识使用方式** 的核心设计。

## 核心目标：防止上下文爆炸

Agent 的上下文窗口有限。一次性加载过多知识会挤占推理空间，导致上下文爆炸。渐进式加载让知识被**克制地检索**出来，只取当前所需。

## 工作方式

```
用户/Agent 提问
  → 检索最匹配的知识点（L2 摘要层）
  → LLM 判断：这些知识够不够？
      → 够 → 直接基于现有知识回答
      → 不够 → 沿知识图谱向外扩展一层
          → 再次判断：够不够？
              → 够 → 回答
              → 不够 → 继续深入...
```

## LLM 的判断角色

**知识够不够，由 LLM 来判断**，不是预设的固定深度。

- LLM 评估当前已加载的知识是否能支撑回答
- 如果信息不足，LLM 决定下一步扩展的方向（沿哪条关系、加载哪些关联知识点）
- 这种柔性判断避免了"要么全加载，要么缺信息"的极端

## 核心特征

| 特征 | 说明 |
|------|------|
| **克制** | 初始检索仅返回最相关的摘要，不过度加载 |
| **按需深入** | 信息不足时才继续探索，不预先加载 |
| **LLM 驱动** | 由 LLM 判断边界，不硬编码检索深度 |
| **图谱导航** | 沿知识图谱的关系边逐层扩展，方向明确 |
