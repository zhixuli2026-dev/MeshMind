# 功能列表

## 知识生命周期管理（SDK 核心）

| 功能 | 说明 | 状态 |
|------|------|------|
| 知识提取 | 从对话/文档中由 LLM 自动提炼知识（实时异步） | 待开发 |
| 知识图谱 CRUD | 知识点的创建、更新、删除 | 待开发 |
| 关系管理 | 知识点之间的关联关系（前置、互补、派生、冲突） | 待开发 |
| 活力值/半衰期 | 知识衰减与激活的自动管理（TimescaleDB 时序存储） | 待开发 |
| 冲突检测 | Law 冲突和跨知识点矛盾的标记 | 待开发 |
| 知识检索 | 直接检索 + 间接加载 + 渐进式加载（向量 + BM25） | 待开发 |
| 入库维护逻辑 | LLM 判断新知识与已有知识的关系（重复/相似/矛盾/新文档） | 待开发 |
| 知识溯源 | 每条知识记录来源（user_id, session_id, source_type） | 待开发 |

## Agent 系统

| 功能 | 说明 | 状态 |
|------|------|------|
| Main Agent | 用户问答入口，编排 spawn 子 Agent | 待开发 |
| Knowledge Agent | React Loop 深度+广度探索知识 | 待开发 |
| Agent Spawn | Agent 之间互相 spawn 研究子课题 | 待开发 |
| React Loop 实现 | LangChain / DeepAgents / 自实现 三选一评估 | 设计阶段 |

## 基础设施

| 功能 | 说明 | 状态 |
|------|------|------|
| LLM Harness (Pro+Flash) | 双模型路由 + 重试 + 超时控制 | 待开发 |
| Embedding (BGE-M3) | 本地 GPU 向量生成 | 待开发 |
| Document Storage (MinIO/S3) | Markdown 文档存储，最大 30MB | 已搭建 |
| JWT + API Key 认证 | 混合认证方案 | 待开发 |
| REST API | FastAPI 端点（12 组） | 待开发 |
| SSE 流式推送 | Agent 过程实时推送（10 种事件） | 待开发 |
