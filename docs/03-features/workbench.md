# Workspace & Workbench

## Workspace 注册流程

每个团队需要注册自己的 Workspace（租户），流程：

1. 用户创建 Workspace，填写团队名称和描述
2. 系统自动创建该 Workspace 的隔离环境（schema、知识图谱空间）
3. 创建者默认为 Workspace 管理员

## Workspace 管理员

管理员拥有以下权限：

| 权限 | 说明 |
|------|------|
| 管理成员 | 添加/移除团队成员 |
| 管理 Law | 定义和维护 Law 类型知识（只有管理员可写入 Law） |
| 知识维护 | 手动删除、编辑、标记知识 |
| Workspace 配置 | 修改团队信息、半衰期参数等配置 |
| 查看分析 | 查看知识图谱状态、活力值分布等 |

## Workbench 前端

Workbench 是管理员的操作面板，包含：

### 知识管理
- 知识图谱可视化（D3.js / Cytoscape.js）
- 知识点列表和搜索
- 手动创建/编辑/删除知识点
- 关系查看和编辑
- 冲突标记查看和处理

### 文档管理
- 文档上传（支持拖拽）
- 文档列表和预览
- 文档拆解状态查看（哪些知识点来源于此文档）

### 分析面板
- 知识总量和类型分布
- 活力值趋势（TimescaleDB 时序数据）
- 半衰期分布
- 知识增长曲线

### 成员管理
- 成员列表
- 贡献统计
- 权限设置

### 设置
- Workspace 基本信息
- 半衰期参数调整
- LLM 提取策略配置
