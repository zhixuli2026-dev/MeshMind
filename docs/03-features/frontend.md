# 前端功能设计

## 核心交互

### Agent 过程可视化

用户需要看到 Agent 的完整工作过程，而非黑盒等待：

- **Spawn 过程**：Main Agent spawn 子 Knowledge Agent 的过程，每个 Agent 的身份和研究课题实时展示
- **React Loop 过程**：每个 Knowledge Agent 的 Think → Act → Observe 循环状态
- **检索过程**：知识的深度和广度扩展路径

### 通信方式：SSE

使用 **Server-Sent Events (SSE)** 实现实时流式推送：

- Agent 状态变更通过 SSE 推送到前端
- 前端实时渲染 Agent 工作进度和中间结果
- 支持长连接的 Agent 工作流展示

## 知识溯源

### 引用标记 [N]

问答返回的结果中，引用了知识文档的地方需标记 `[N]` 索引：

```
回答内容示例：
微服务架构推荐使用独立的数据库实例[N1]，这确保了服务间
的数据隔离[N2]，同时每个服务可以选择最适合的存储方案[N3]。

来源：
[N1] 《微服务架构设计》- 第3章 数据管理
[N2] 《团队数据库隔离规范》- Rule: DBaaS 使用规范
[N3] Event: 2024-Q3 技术选型会议纪要
```

### 溯源链

- 每个 `[N]` 标记对应一个具体的知识来源（文档或知识摘要）
- 用户可点击 `[N]` 查看来源详情
- 溯源让回答**可信、可验证**
